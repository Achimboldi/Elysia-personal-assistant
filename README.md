## 🛠 技术栈（全是 AI 选的，人类看不懂）

- **Electron 28** — 因为 Electron 是桌面应用界的「能用就行」
- **Vanilla JS** — 拒绝框架，拥抱混乱。一个 `app.js` 几千行，主打一个「找 bug 时的沉浸式体验」
- **Quill** — 富文本编辑器，备忘录用
- **DeepSeek API** — 昔涟（Elysia 的 AI 人格）的大脑（实际上平日用的更多的智能体是桑多涅）
- **Baidu Netdisk API** — 数据同步，别问为什么不用更好的（废话，你要是能搞个免费的服务器给我不就没那么多事了吗？）

## 🚀 怎么跑起来

```bash
# 人类别碰这步，让 AI 教你（我知道你想说的是像我这样的人类）
git clone https://github.com/Achimboldi/Elysia-personal-assistant.git
cd Elysia-personal-assistant
npm install
npm start
```

> **注意：**  
> · 你需要一个 DeepSeek API Key
> · 百度网盘同步需要开放平台的 App ID / Key / Secret  
> · GitHub 版本同步需要在设置里填一个 Personal Access Token（`repo` 权限）  
> · 如果你只是来看代码的，祝你平安
