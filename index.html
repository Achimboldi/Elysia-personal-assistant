说明

备忘录 Markdown 快捷键

备忘录编辑器内置了类飞书 / Notion 的 Markdown 快捷输入，无需使用工具栏。 在行首输入对应符号后按 空格 或 回车 即可自动转换为对应格式； 行内样式在输入成对的标记后按 空格 触发。

标题

输入（行首）效果
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

列表

输入（行首）效果
- 或 * 或 + 无序列表
1. （2. 3. 同理）有序列表

引用 / 代码块 / 分割线

输入（行首）效果
> 引用块
``` 代码块
--- / *** / ___ 分割线（独立一行）

行内样式（成对标记 + 空格触发）

输入效果
**文字** 或 __文字__粗体
*文字* 或 _文字_斜体
~~文字~~删除线
`文字`行内代码
提示：成对标记需紧邻文字，输入完整后按一下 空格 即转换。例如输入 **重点** 会自动变为加粗的「重点」。

链接

操作效果
在备忘录里粘贴一个网址自动变成可点击链接（显示网页标题）
粘贴含网址的整段文字其中的网址自动识别为链接
点击编辑器内的链接调用系统默认浏览器打开该网页

表格

在空白行输入 =表格 后按 回车，即可生成一张默认的 3×3 表格（首行为表头「表头1 / 表头2 / 表头3」，下方两行为空数据行）。= 是退格键旁边的单键，无需组合，其他快捷键未占用。

输入（行首）效果
=表格生成默认 3×3 表格
=【表格】同样生成默认 3×3 表格
| 姓名 | 年龄 | 城市 |（兼容旧式）生成 3 列表格，表头为你写的文字
生成后鼠标移到表格上会浮现边缘控件：
• +（右侧）= 在右方插入一列；+（下方）= 在下方插入一行
• −（红色，右侧）= 删除鼠标所指的那一列；−（红色，下方）= 删除鼠标所指的那一行
把鼠标悬停到想删的列/行上再点红色「−」即可精确删除（至少保留 1 列 / 1 行）。点击单元格即可直接编辑内容。

格式继承

在带格式的行（如加粗、引用、代码块）末尾按 回车 换行后，新行不会继承上一行格式（与飞书 / Notion 一致），可放心继续输入普通文字。
