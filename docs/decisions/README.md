# 决策记录（ADR）

> Architecture Decision Records：记录重要架构/设计决策的来龙去脉，回答"为什么这么做"。当一次改动包含值得后人知道的决策时，在这里新建一个文件。

## 模板

文件名：`YYYY-MM-DD-短横线标题.md`

```markdown
# ADR: <决策标题>

- 日期：YYYY-MM-DD
- 状态：已采纳 | 提案 | 已废弃

## 背景
<当时面临什么问题/约束>

## 决策
<做了什么选择>

## 原因
<为什么选这个方案，备选方案为什么不选>

## 影响
<对代码/数据/用户/后续开发的影响>

## 相关
<链接到相关代码、文档、工作日志>
```
